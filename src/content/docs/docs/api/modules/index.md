The per-version Module APIs reference (`/docs/api/modules/v/0.20`, `/v/1.0`,
`/v/1.3`) was retired with the migration to Astro — version-pinned API docs
are now maintained inside each Node-RED release tag on GitHub.

For the current runtime APIs, see:

- [Runtime API](/docs/api/runtime/)
- [Module API](/docs/api/modules-api/) (current shape, used by node packages)
- [Editor UI Widgets](/docs/api/ui/)

For a historical version-pinned snapshot, browse the corresponding tag at
[github.com/node-red/node-red/tree/v0.20.0/docs](https://github.com/node-red/node-red/tree/v0.20.0/docs).
